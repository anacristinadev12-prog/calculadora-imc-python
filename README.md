# Calculadora de IMC em Python

Um projeto simples e interativo em Python para calculo do Indice de Massa Corporal (IMC), com validacao de dados e tratamento de excecoes.

## Funcionalidades
- Recebe peso e altura do usuario via terminal
- Calcula o IMC com base na formula padrao
- Exibe a classificacao nutricional (Abaixo do peso, Peso normal, Sobrepeso, Obesidade)
- Tratamento de erros com try/except para impedir falhas caso o usuario digite letras ou virgulas

## Tecnologias
- Python 3
- Git e GitHub

## Como executar
No terminal, execute:
```bash
python app.py
