# Calculadora de IMC em Python

Um projeto simples e interativo em Python para cálculo do Índice de Massa Corporal (IMC), com validação de dados e tratamento de exceções.

## Funcionalidades
- Recebe o peso e a altura do usuário via terminal.
- Calcula o IMC com base na fórmula padrão.
- Exibe a classificação nutricional (Abaixo do peso, Peso normal, Sobrepeso, Obesidade).
- Realiza o tratamento de erros com `try/except` para impedir falhas caso o usuário digite letras ou vírgulas.

## Tecnologias
- Python 3
- Git e GitHub

## Como executar
No terminal, execute:
```bash
python app.py
